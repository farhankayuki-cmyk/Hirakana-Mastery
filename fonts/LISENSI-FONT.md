# Lisensi font

Font di folder ini adalah versi yang dipotong hanya berisi huruf kana (hiragana dan katakana) dari font bebas berlisensi SIL Open Font License 1.1 (https://openfontlicense.org). Boleh dipakai, disalin, dan dimodifikasi, termasuk untuk keperluan komersial.

| File | Font asli | Hak cipta |
|---|---|---|
| gothic.woff2 | Noto Sans JP (wght 500) | The Noto Project Authors |
| mincho.woff2 | Noto Serif JP (wght 600) | The Noto Project Authors |
| kyokasho.woff2 | Klee One SemiBold | The Klee Project Authors (Fontworks) |
| tangan.woff2 | Yomogi | Satsuyako (Yomogi Project Authors) |
| kuas.woff2 | Yuji Syuku | The Yuji Project Authors |

Sumber: https://github.com/google/fonts (folder ofl/).
